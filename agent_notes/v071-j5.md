## 3. Build fixes (the promotion was NOT a pure verbatim copy)

The first app build (run 41909195746, head 69021ed) failed:
`'pthread_jit_write_protect_np' is unavailable in iOS`. The
function is declared for macOS only in the SDK headers. Two
fixes followed, applied identically to BOTH NovaJIT.swift
copies so they stay byte-identical, same underlying function,
same arguments at every call site:

1. Bind the symbol via `@_silgen_name` instead of the imported
   declaration (head ccd37da). This fixed compilation; the
   build then failed at LINK (run 41909577597): the iOS link
   stubs omit `_pthread_jit_write_protect_np` entirely
   (undefined symbol, referenced from probe/runTrampoline).
2. On iOS the function is now resolved once with
   `dlsym(RTLD_DEFAULT, "pthread_jit_write_protect_np")` — it
   exists in the iOS runtime libsystem (the standard route for
   sideloaded JITs); if it were absent, the toggle is a no-op
   and the probe's smoke test fails that allocation path
   honestly. On macOS the direct silgen bind is kept, so the
   macOS gate exercises exactly the code path J4 gated
   (head 40d58e2). All gates in §2 were re-run green on the
   final code.
